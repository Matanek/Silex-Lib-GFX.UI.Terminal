# GFX.UI.Terminal

`GFX.UI.Terminal` adds composable ANSI/VT system-terminal and
application-console controls to GFX.UI.

```text
silex install GFX.UI.Terminal
```

## Documentation

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

The package requires Silex 0.43.0 or newer.
